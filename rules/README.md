# Rules reference

One file per playable wonder, all with the same sections: Overview, Goal, Players, Board and pieces, Setup, Turn, Movement, Attacks and captures, Special rules, End of the game, Four players, Implementation notes.

The wording players see in the game is the `RULES` table in `src/main.js`; the logic is `src/<id>/rules.js`. When a rule changes, change all three.
